## Soccer Code Coach

This repo now includes `soccer-code-coach`, a browser app that teaches Java and
Python step by step with soccer-themed explanations, examples, quizzes, and
practice drills.

To run it locally:

```bash
cd soccer-code-coach
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
